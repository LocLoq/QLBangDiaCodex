Historical sale-return conditions and barcodes can only be reconstructed where sufficient audit information remains. A row-ordered SHA-256 comparison of every column shared before and after migration matched for all orders, order lines, payment transactions and physical copies. Removed legacy columns and newly added columns are outside that comparison.

It also checked the rendered revenue, damage and genre charts, the purchase filter, and overview tabs for popular rentals/sales, low stock, discovery discounts, random titles and a future-title preorder. It does not simulate every dialog action. A clean-machine installer acceptance test also remains outstanding.

The interaction check additionally verified manually entered custom date ranges with and without transactions, and exported a CSV containing stockout and genre sections plus a valid PNG chart to a temporary directory. Long GUI runs exposed Tkinter variables from the discovery-discount dialog being collected on a background thread. The dialog now releases those variables on the UI thread when saved or closed; the full interaction check passed afterwards with guards against background-thread variable destruction and unhandled Tk callbacks, exercising both save and window-close paths.

Windows Sandbox and Hyper-V management tools exist on the host, but checking the Sandbox feature and listing virtual machines returned Windows access-denied/elevation errors. A clean-machine installation therefore has not been verified.

An isolated Sandbox installer check was prepared in `build/normastore-review-1e65659e50/sandbox-check` with networking disabled, read-only installer/MySQL mappings and a separate output mapping. Sandbox launcher PID 23768 was started hidden on 2026-11-22; it was still running without a result file at the latest check. Do not launch another instance until the existing process and `output/result.json` have been checked.

`hcsdiag list` reports that Windows administrator or Hyper-V Administrators group membership is required to inspect virtual machines or containers. The Sandbox launcher's precise state remains unconfirmed; a suitable Windows test environment or the required Windows permissions is needed for further diagnosis.
